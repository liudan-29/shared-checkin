# 三人小组界面预览设计说明

## 三人票据

画面把三个人的日程视为同一张被并排裁开的打卡票据。暖纸底色与细点阵承接原产品的记录感，三列计划以完全等宽的节奏出现，让成员关系保持平等，没有谁被放在主位或次位。

墨蓝承担可执行、已完成和连接状态，朱红只用于拖延提示。综合色彩保持克制，使三列同时出现时仍可快速看见真正需要关注的成员和时段。每个图形、分割线和状态章都按真实产品的比例细致校准。

顶端的小组头像和中部的留言横条负责把三个独立的计划连接起来。信息不靠长段说明，而通过并列、进度孔和状态印章表达谁在进行、谁已完成、谁需要被提醒。

移动端不缩小三列，而是保留成员切换。预览中的手机小样显示三个人各自拥有完整阅读宽度，顶部成员缩略信息始终可见。整张图按高密度但不拥挤的编辑版面制作，每一个边距、字重与阴影都经过反复收敛。

成图强调真实产品感而不是概念海报感。它像一个被精心制作出来的界面状态样本，视觉层级、触控区域和信息节奏都能直接指导后续实现。
