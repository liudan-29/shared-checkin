# 双人共享打卡作品集图设计说明

## 票据

画面以打卡票据为核心意象。暖纸色、点阵、虚线撕边和印章共同建立可触摸的记录感，让监督行为看起来像每天留下的一张真实凭证，而不是普通效率工具的后台界面。

版式采用左侧叙事、右侧产品的非对称构图。左侧只保留产品名、核心价值和三项能力，右侧用大面积真实界面承担主要信息。视线先落在标题与蓝色印章，再自然进入双人计划、完成状态和留言互动。

颜色只使用墨蓝、朱红和暖纸中性色。墨蓝对应完成与可靠，朱红只标记拖延与需要关注的状态。克制的色彩让作品集缩小到简历尺寸后仍有清晰的视觉层级。

界面数据全部是演示内容，但保留真实产品的结构：双人时段并列、实时进度、产出记录、拖延反馈和公开留言。每一块信息都能独立说明一个功能，同时组合成完整的使用场景。

细节强调完成度：浏览器窗口、打孔进度条、时间编号、墨水章和轻微错位的纸张层叠都经过统一比例控制。文字尽量少，让招聘者在几秒内理解产品解决的问题和主要交互。
